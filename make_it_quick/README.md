# Make it Quick

This script is built for speed. The Leviathan looms over every game, guaranteeing an evil victory within five days unless the town can hunt it down in time, so there's no room to stall. Backing that urgency up is a deep bench of direct-kill roles, including the Slayer, Assassin, Huntsman, Bounty Hunter, and Psychopath, any of whom can end the game in a single swing.

Expect fast, decisive rounds where hesitation is punished and someone is always one bold accusation away from ending it all.
